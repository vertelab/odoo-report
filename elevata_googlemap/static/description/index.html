Google Map View | Contacts Google Map View | Partners Google Map View | Map View

This Odoo module adds a map view to the contact model using existing latitude and longitude fields. It allows you to display the location on the map and enables users to change the location by dragging the marker.

Installation

- Copy web_googlemap module to addons folder

- Install the module normally like other modules

1. Set Google Map API Key

Settings -> Google Map -> Set API keys


2. Set latitude and longitude

Contacts -> Contact -> Partner Assignment


3. Map View

Contacts -> Map View
